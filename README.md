# Netflix Data Analysis

This project performs exploratory data analysis on Netflix's catalog of movies and TV shows.

## Objective

To analyze trends in Netflix content such as:

* Distribution of movies vs TV shows
* Growth of Netflix content over time
* Countries producing the most content
* Content rating distribution
* Most common genres

## Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

## Key Insights

* Movies dominate Netflix's catalog.
* Netflix's content library expanded rapidly after 2016.
* The United States produces the most titles.
* TV-MA and TV-14 ratings are the most common.
* International Movies, Dramas, and Comedies are popular genres.

## Dataset

Netflix Movies and TV Shows Dataset from Kaggle.
